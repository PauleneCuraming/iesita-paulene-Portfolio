The portfolio website itself uses:

No database or additional npm dependencies are required to run the portfolio locally.

## How to Download and Run Locally

### Prerequisites

Make sure you have:

- A computer with Windows, macOS, or Linux
- A modern web browser
- Node.js installed
- Visual Studio Code or another code editor (optional)

### Step 1 — Download the Project

Open the portfolio's GitHub repository.

Select **Code → Download ZIP**, then extract the downloaded ZIP file.

Alternatively, clone the repository using Git:

```bash
git clone <repository-url>
```

Replace `<repository-url>` with the actual GitHub repository URL.

### Step 2 — Open the Project

Open the extracted portfolio folder in Visual Studio Code.

Make sure you are in the folder containing `index.html` and `server.js`.

### Step 3 — Start the Local Server

Open the integrated terminal and run:

```bash
node server.js
```

### Step 4 — Access the Portfolio

Open your browser and visit:

http://localhost:8000

The portfolio should now be accessible on your local computer.

To stop the local server, return to the terminal and press `Ctrl + C`.
